# ئەکاونت، ڕۆڵ و چوونەژوورەوە — Accounts, Roles & Login

> ڕێبەری کارکردن بە سیستەمی بەکارهێنەران لە Galo Kids
> (Working guide for the Galo Kids user/role system)

---

## ١. ڕۆڵەکان — The role scheme

| ژمارە | ڕۆڵ | Role | چی دەتوانێت بکات |
|------|-----|------|------------------|
| `0` | کڕیار | Customer | کڕین، داواکارییەکانی خۆی، پرۆفایلی خۆی |
| `1` | بەڕێوەبەر | Admin | هەموو شتێک: داشبۆرد، ڕێکخستنەکان، بەکارهێنەران، ڕاپۆرتەکان، POS |
| `2` | کاشێر | Cashier | تەنها POS: فرۆشتن، شیفت، کڕیار زیادکردن |
| `3` | کارمەند | Staff | POS + بەڕێوەبردنی کاڵا و داواکارییەکان (بەبێ ڕێکخستنی گشتی) |

ئەم ژمارانە لە هەموو شوێنێکی سیستەمەکەدا وەک یەکن:

- Frontend: `src/utils/roles.ts`
- Backend: `laravel-backend/app/Support/Roles.php`
- Database: کۆڵۆمی `users.role`

> **ئاگاداری گرنگ / Important:** لە وەشانی کۆنی ئەم پڕۆژەیەدا واتای ژمارەکان جیاواز بوو
> (`1 = کڕیار`, `2 = کارمەند`, `3 = بەڕێوەبەر`). ئەگەر داتابەیسەکەت لەو کاتەوە ماوە،
> ئەوا هەموو کڕیارە کۆنەکان وەک **بەڕێوەبەر** دەردەکەون و بەڕێوەبەرە ڕاستەقینەکەش وەک **کارمەند**.
> بەشی ٣ ڕوونی دەکاتەوە چۆن چاکی بکەیت.

## ٢. چۆن کڕیار خۆتۆمار دەکات و دەچێتە ژوورەوە — Customer sign-up / sign-in

هەموو ئەکاونتێکی کڕیار بە **ژمارەی مۆبایل** دەناسرێتەوە. ژمارەکە هەمیشە بە یەک فۆرماتی
یەکگرتوو هەڵدەگیرێت — `9647501234567` — واتە `0750…`، `+964750…` و `750…` هەموویان
دەگەڕێنەوە بۆ هەمان ئەکاونت (تەنها یەک ئەکاونت بۆ هەر ژمارەیەک).

```
١) کڕیار ژمارەکەی دەنووسێت
        │
        ▼
٢) POST /api/send-otp          → کۆدی ٦ ژمارەیی بە SMS/WhatsApp دەنێردرێت
        │                        (٥ خولەک ماوەی، ٤٥ چرکە نێوان دوو داواکاری)
        ▼
٣) POST /api/verify-otp        → کۆدەکە پشتڕاست دەکرێتەوە
        │                        وەڵام: verification_token (یەک جار بەکاردێت، ١٠ خولەک)
        ▼
٤) POST /api/login-with-phone  → بە verification_token ئەکاونت دەکرێتەوە/دروست دەکرێت
                                 وەڵام: access_token (Bearer)
```

**بۆچی `verification_token` گرنگە؟** پێشتر هەنگاوی ٤ تەنها ژمارەی مۆبایلی دەویست.
واتە هەرکەسێک دەیتوانی ژمارەی کەسێکی تر بنووسێت و بچێتە ناو ئەکاونتەکەیەوە — بەبێ هیچ کۆدێک.
ئێستا بەبێ ئەو تۆکنە سێرڤەرەکە ڕەتی دەکاتەوە.

### ئایا ئەم ژمارەیە تۆمارکراوە؟

`POST /api/auth/phone-status` → `{ "exists": true, "name": "Awat H." }`

لاپەڕەکانی چوونەژوورەوە و خۆتۆمارکردن ئەمە بەکاردەهێنن. پێشتر تەنها لە بیرگەی وێبگەڕ
(localStorage) دەیانپرسی — بۆیە هەر کڕیارێک لە مۆبایل/کۆمپیوتەرێکی نوێوە هەوڵی
چوونەژوورەوەی دەدا، پەیامی «ئەم ژمارەیە تۆمار نەکراوە»ی بۆ دەردەکەوت.

### چوونەژوورەوە بە وشەی تێپەڕ

`POST /api/login` بە `login` (ئیمەیڵ یان ژمارەی مۆبایل) + `password`.
ئەمە بۆ بەڕێوەبەر، کاشێر و کارمەندە — و بۆ ئەو کڕیارانەی وشەی تێپەڕیان بۆ خۆیان داناوە.

## ٣. چاککردنی ڕۆڵەکان لەسەر سێرڤەر — Repairing roles on the server

هەموو ئەم فەرمانانە لە ڕیشەی `laravel-backend` جێبەجێ دەکرێن.

### بینینی هەموو ئەکاونتەکان و ڕۆڵەکانیان

```bash
php artisan users:list-roles              # هەمووی
php artisan users:list-roles --privileged  # تەنها ئەدمین/کاشێر/کارمەند
php artisan users:list-roles --role=1      # تەنها ئەدمینەکان
```

لە کۆتاییدا ژمارەی هەر ڕۆڵێکت پیشان دەدات، و ئەگەر هیچ ئەدمینێک نەبێت ئاگادارت دەکاتەوە.

### گۆڕینی ڕۆڵی ئەکاونتێک

```bash
# بەڕێوەبەر کردنی ئەکاونتەکەت (بە ئیمەیڵ، ژمارەی مۆبایل، یان ID)
php artisan users:set-role admin@galokids.com admin
php artisan users:set-role 07501234567 admin

# کاشێر / کارمەند / کڕیار
php artisan users:set-role 07501112233 cashier
php artisan users:set-role 42 staff
php artisan users:set-role 07509998877 customer

# لەگەڵ دانانی وشەی تێپەڕێکی نوێ
php artisan users:set-role 07501234567 admin --password=NewSecret123
```

فەرمانەکە ڕێگە نادات دوایین ئەدمین لابدرێت، بۆیە ناتوانیت خۆت لە داشبۆردەکەت دەرکەیت.

### چاککردنی داتای کۆن (legacy)

ئەگەر داتابەیسەکەت پێش گۆڕینی سیستەمی ڕۆڵەکان دروستکراوە:

1. `php artisan users:list-roles` بکە و لیستەکە ببینە.
2. ئەو ئەکاونتانەی `role = 3`ن و لە ڕاستیدا بەڕێوەبەرن → `users:set-role <ئەکاونت> admin`
3. ئەو ئەکاونتانەی `role = 1`ن و لە ڕاستیدا کڕیارن → `users:set-role <ئەکاونت> customer`
4. کاشێرەکان لە `2` دەمێننەوە (نەگۆڕاون).

بەئەنقەست بە دەستی ئەنجام دەدرێت: هیچ migration-ێک ناتوانێت بزانێت ئایا ژمارەکانی
داتابەیسەکەت بەپێی سیستەمی کۆنن یان نوێ، و هەڵەیەک لەوێدا دەتوانێت هەموو کڕیارەکان بکات
بە بەڕێوەبەر یان بەڕێوەبەرەکەت لە سیستەمەکە دەربکات.

> `2026_08_10_000001_set_users_role_default_to_customer` تەنها **default**ی کۆڵۆمەکە
> لە `1` (بەڕێوەبەر!) دەگۆڕێت بۆ `0` (کڕیار). ڕیزە بەردەستەکان دەستیان لێ نادرێت.
> ئەمە گرنگە: پێشتر هەر ئەکاونتێک بەبێ `role`ی ڕوون دروستدەکرا، دەبووە بەڕێوەبەر.

## ٤. زیادکردنی بەکارهێنەر لە داشبۆردەوە — Adding users from the dashboard

`داشبۆرد → بەکارهێنەران → دروستکردنی بەکارهێنەر`

- **کڕیار (0)**: تەنها ناو + ژمارەی مۆبایل بەسە. وشەی تێپەڕ پێویست نییە (بە OTP دەچێتە ژوورەوە).
- **بەڕێوەبەر / کاشێر / کارمەند**: ناو + ئیمەیڵ + وشەی تێپەڕ (لانیکەم ٨ پیت) پێویستە.

ڕێسا ئاسایشییەکان کە سێرڤەر جێبەجێیان دەکات:

- تەنها **بەڕێوەبەر** دەتوانێت ئەکاونتی بەڕێوەبەر/کاشێر/کارمەند دروست بکات، بگۆڕێت یان بسڕێتەوە.
- کاشێر و کارمەند تەنها کڕیار بەڕێوە دەبەن — ناتوانن خۆیان بەرزبکەنەوە.
- دوایین ئەکاونتی بەڕێوەبەر ناسڕدرێتەوە و ڕۆڵەکەی ناگۆڕدرێت.
- ژمارەی مۆبایل بە فۆرماتی یەکگرتوو هەڵدەگیرێت و دووبارە نابێتەوە.

## ٥. ڕێکخستنی `.env` — Required configuration

```env
# OTPIQ — کلیلەکە دەبێت لێرە بێت، نەک لە ناو کۆدەکە
OTPIQ_API_KEY=sk_live_...
OTPIQ_API_URL=https://api.otpiq.com/api/sms

# تەنها بۆ تاقیکردنەوە. لە پڕۆدەکشن دەبێت بەتاڵ بێت!
OTP_TEST_CODE=
```

> ⚠️ کلیلی OTPIQ پێشتر ڕاستەوخۆ لە ناو `OtpController.php`دا نووسرابوو و لەگەڵ کۆدەکە
> بڵاوکراوەتەوە. **پێویستە لە داشبۆردی OTPIQ کلیلێکی نوێ دروست بکەیت** و کۆنەکە بسڕیتەوە،
> چونکە هەرکەسێک کۆدەکەی بینیبێت دەتوانێت کرێدیتی SMSـەکەت بەکاربهێنێت.

هەروەها `OTP_TEST_CODE`: ئەگەر پڕ بکرێتەوە، ئەو کۆدە بۆ **هەموو** ژمارەیەک قبوڵ دەکرێت.
لە پڕۆدەکشن بەتاڵی بهێڵەوە — پێشتر کۆدی `123456` بە شێوەی چەسپاو لە کۆدەکەدا قبوڵ دەکرا،
واتە هەرکەسێک دەیتوانی بە هەر ژمارەیەک بچێتە ژوورەوە.

## ٦. کورتەی API — Endpoint summary

| Endpoint | Access | Notes |
|----------|--------|-------|
| `POST /api/send-otp` | گشتی | ٤٥ چرکە cooldown بۆ هەر ژمارەیەک |
| `POST /api/verify-otp` | گشتی | ٥ هەوڵی هەڵە → کۆدەکە دەسڕدرێتەوە |
| `POST /api/auth/phone-status` | گشتی | `{exists, name}` — ناوێکی شاردراوە |
| `POST /api/login-with-phone` | گشتی | `verification_token` پێویستە |
| `POST /api/login` | گشتی | ئیمەیڵ/مۆبایل + وشەی تێپەڕ |
| `POST /api/register` | گشتی | هەمیشە کڕیار (role 0) دروست دەکات |
| `GET /api/users` | ئەدمین/کاشێر/کارمەند | |
| `POST|PUT|DELETE /api/users` | ئەدمین بۆ ئەکاونتی تایبەتمەند | |
| `PUT /api/settings` | تەنها ئەدمین | |
| `GET /api/shifts` | تەنها ئەدمین | مێژووی شیفتەکان |
| `GET /api/reports/cashiers` | تەنها ئەدمین | |
